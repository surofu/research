## Методы и инструменты дизайн-мышления

| **Метод**                         | **Описание**                                                             | **Когда подходит**                                            |
| --------------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------- |
| **Интервью с пользователями**     | Помогает понять потребности, ожидания и проблемы аудитории               | Когда нужно глубже изучить пользователей перед началом работы |
| **Мозговой штурм**                | Команда генерирует большое количество идей без их немедленной оценки     | Для поиска разных вариантов решения одной задачи              |
| **Crazy 8s**                      | Участники за ограниченное время предлагают несколько концепций решения   | Когда важно быстро найти нестандартные идеи                   |
| **Прототипирование**              | Создание простой версии продукта или функции для проверки гипотезы       | Перед разработкой полноценного решения                        |
| **Пользовательское тестирование** | Проверка решения с участием реальных пользователей и сбор обратной связи | Чтобы выявить проблемы и улучшить продукт до запуска          |

Инструменты помогают применять методы дизайн-мышления на практике: исследовать аудиторию, анализировать информацию и визуализировать результаты.

| **Инструмент**                  | **Для чего используют**                                                                      |
| ------------------------------- | -------------------------------------------------------------------------------------------- |
| **Карта эмпатии (Empathy Map)** | Помогает структурировать знания о пользователях: что они думают, чувствуют, говорят и делают |
| **Customer Journey Map (CJM)**  | Позволяет визуализировать путь пользователя и определить точки, где возникают сложности      |
| **Персона (Persona)**           | Создаёт обобщённый портрет представителя целевой аудитории для принятия проектных решений    |
| **Miro, FigJam**                | Используют для совместной работы, мозговых штурмов и визуализации идей                       |
| **Figma**                       | Применяют для создания прототипов и проверки пользовательских сценариев                      |
